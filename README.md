# Desafio CSS – Landing Page de Corridas

Landing page estática feita com **HTML** e **CSS** puro, como desafio de reprodução de layout. A página apresenta um serviço de corridas compartilhadas, com menu de navegação, ilustração e uma seção de destaque com chamada para ação.

## 📸 Visão geral

- **Header** com links de navegação (Product, Company, Blog, Login) e botão de cadastro
- **Ilustração** principal ao lado esquerdo
- **Seção de destaque** com título *"Wide coverage location"*, texto descritivo e botão *"Saiba mais"*

## 🛠️ Tecnologias

- HTML5
- CSS3
- [Google Fonts – Poppins](https://fonts.google.com/specimen/Poppins)

## 🚀 Como rodar

Não precisa instalar nada. Basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone <url-do-repositorio>
cd desafio
```

Depois, abra o arquivo `index.html` com duplo clique ou use a extensão **Live Server** do VS Code.
